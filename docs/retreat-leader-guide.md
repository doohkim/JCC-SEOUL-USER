# 조장·부조장 사용 가이드

수련회 앱을 조장·부조장 권한으로 이용하는 방법을 안내합니다.

## 접근 권한

- **참가자**: 수련회 메뉴 접근 불가
- **조장·부조장**: 본인이 맡은 **조** 정보만 조회·수정 가능
- **수련회 회장단**: 전체 조 정보 조회·편집 가능

---

## 1. 대시보드 — 실시간

집회를 선택한 뒤 **대시보드** 탭에서 실시간 현황을 확인합니다.

![](retreat/guides/01.png)

1. **집회 선택** — 상단에서 연도·집회(예: 2026년 수련회)를 고릅니다.
2. **실시간 참석** — 현재 입실 인원 / 총 참석 대비 비율입니다. 카드를 누르면 **조 관리**로 이동합니다.
3. **숙소 배정** — 배정 인원·잔여 객실 수입니다. (운영 기능은 회장단 위주)
4. **차량 지원(오늘)** — 오늘 픽업이 필요한 인원(입실전) 수입니다. 카드를 누르면 **픽업** 탭으로 이동합니다.
5. **실시간 참석 인원 표** — 조별·지역·부서별 현재 입실 인원입니다.
6. **지역·부서별 인원체크** — 입실전 / 입실 / 퇴실 / 참석 인원입니다.
7. **자동 갱신** — 1분마다 자동 반영되며, **새로고침**으로 즉시 갱신할 수 있습니다.

**조 참석현황** 하위 탭에서는 지역별 보드 형태로 조원 명단을 볼 수 있습니다.

![](retreat/guides/02.png)

1. **지역 필터** — 전체 또는 특정 지역만 표시합니다.
2. **전체 요약** — 선택 지역의 입실전·입실·퇴실·총 인원입니다.
3. **지역·부서 헤더** — 펼치기/접기로 구역을 나눕니다.
4. **조 카드** — 조별 참석 인원과 조원 이름·상태입니다.
5. **부서별 요약** — 해당 부서의 조 수·참석·입실전 인원입니다.

---

## 2. 조 관리 — 조 목록

**조 관리** 탭에서 담당 조 카드를 선택해 조원 명단으로 들어갑니다.

![](retreat/guides/04.png)

1. **지역·부서 필터** — 칩을 눌러 원하는 조만 골라 볼 수 있습니다. (회장단·전체 조 보기 시)
2. **조 카드** — 지역·부서·조 이름·조장·조원 수가 표시됩니다. 카드를 누르면 **조원 리스트**로 이동합니다.
3. **조 수정** — 연필 아이콘(회장단·관리 권한만 노출).
4. **조 추가** — 우측 상단 버튼(회장단·관리 권한만 노출).

조 추가·수정 화면(회장단용) 요약:

![](retreat/guides/05.png)

- 집회 선택, 조 이름, 대표 지역·부서, 추가 지역·부서, 운영진(조장·부조장) 연결 후 **저장**합니다.

---

## 3. 조원 리스트

조 카드를 선택하면 해당 조의 **조원 명단**이 열립니다.

![](retreat/guides/06.png)

![](retreat/guides/07.png)

0. **조 수정** — 조 정보 수정(회장단·관리 권한).
1. **집회 선택** — 다른 집회로 전환할 때 사용합니다.
2. **입실전·입실·퇴실·총** — 조원 상태 요약입니다.
3. **이름·역할** — 행을 누르거나 **수정**으로 조원 정보를 편집합니다.
4. **입실 시각** — 예상 입실 시각을 입력합니다. 시각이 지나면 자동으로 **입실** 처리됩니다.
5. **퇴실 시각** — 예상 퇴실 시각을 입력합니다. 시각이 지나면 자동으로 **퇴실** 처리됩니다.
6. **삭제(제거)** — 조원을 명단에서 제거합니다. (조장·부조장·회장단)
7. **조원 추가** — 우측 상단 **+** 버튼으로 새 조원을 등록합니다.

날짜·시간 선택기:

- **지우기** — 값을 비웁니다.
- **지금** — 현재 시각을 넣습니다.
- **확인** — 선택한 값을 반영합니다. (분 단위는 5분 간격)

---

## 4. 조원 추가·수정

**조원 추가** 또는 행 **수정** 시 아래 항목을 입력합니다.

![](retreat/guides/08.png)

1. **구분** — 조장 / 부조장 / 조원
2. **사용자 계정 연결(선택)** — 가입한 계정이 있으면 검색해 연결합니다. 비우면 명단만 추가됩니다.
3. **실명** — 필수
4. **성별** — 필수
5. **핸드폰 번호** — 선택
6. **입실 시각** — 선택. 매분 자동 상태 전환에 사용됩니다.
7. **퇴실 시각** — 선택. 매분 자동 상태 전환에 사용됩니다.
8. **숙소 배정** — 본부에서 배정한 호실이 있으면 선택합니다.

**저장**을 눌러야 반영됩니다.
