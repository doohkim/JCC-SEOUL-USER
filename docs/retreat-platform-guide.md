# 수련회 관리 플랫폼 가이드

실시간 데이터 기반의 효율적인 수련회 운영을 위한 통합 관리 플랫폼의 주요 기능과 사용 방법을 소개합니다.

## 플랫폼 개요 및 권한 체계

### 플랫폼 개요

- 교회 수련회 참석 인원, 조 구성, 픽업, 숙소 배정 통합 관리
- **1분마다 자동 새로고침** — 실시간 데이터 제공 (실시간 동기화)

### Tier 1 · 참가자

플랫폼 접근 불가 · 제한됨

- 대시보드 조회 불가
- 조 정보 접근 없음

### Tier 2 · 조장/부조장

자기 조 관리 가능 · 부분 권한

- 전체 조 정보 조회 가능
- 자기 조 조원 추가 및 권한 부여

### Tier 3 · 수련회 회장단

전체 관리 권한 · 전체 권한

- 전체 조 추가·수정·삭제
- 숙소 배정 및 대시보드 전체 접근

---

## 대시보드: 실시간 참석 및 지역별 현황

1분 단위로 업데이트되는 전체 참석 인원과 지역·부서별 입실·퇴실 현황을 실시간으로 확인합니다.

### 실시간 참석 인원

현재 **입실 인원** (1분마다 자동 업데이트) — 예시 **3명**

- **5조** (부산대학부) · 1명
- **20조** (부산대학부) · 0명
- **21조** (인천대학부) · 0명
- **22조** (부산대학부) · 0명

### 지역·부서별 입실 현황

*참석 = 입실 + 퇴실 합산*

| 지역/부서 | 입실전 | 입실 | 퇴실 | 참석 |
| --- | --- | --- | --- | --- |
| 부산대학부 (5~22조) | 0 | 1 | 2 | 3 |
| 서울대학부 (3조) | 0 | 1 | 0 | 1 |
| 서울청년부 (1~2조) | 2 | 0 | 1 | 1 |
| 인천대학부 (4~21조) | 6 | 0 | 0 | 0 |

---

## 대시보드: 시간대별 추이 및 빠른 이동

시간대별 입·퇴실 데이터 추이 분석과 주요 관리 탭으로 즉시 이동할 수 있는 바로가기 기능을 제공합니다.

### 시간대별 입·퇴실 추이

1시간 단위로 집계된 입실/퇴실 현황을 시간순으로 확인합니다.

### 빠른 이동

- **현재 입실 인원** — 조 관리 탭으로 이동
- **오늘 픽업 인원** — 픽업 탭으로 이동
- **입실전 인원** — 숙소 관리 탭으로 이동 (개발 중)

---

## 조 관리 목록 및 필터링

### 지역·부서별 필터링

서울 / 부산 / 인천 등 지역과 부서를 조합해 원하는 조를 빠르게 탐색합니다.

### 조 카드 목록 보기

조장 이름과 조원 수가 카드 형태로 한눈에 표시됩니다.

- **2조** — 조장: 없음, 조원 1명 · 서울청년부
- **5조** — 조장: 김일, 조원 3명 · 부산대학부
- **3조** — 조장: 없음, 조원 1명 · 서울대학부

### 조 편집 및 추가 (관리자 전용)

수련회 회장단만 **+ 조 추가**, 조 편집, 삭제 권한을 보유합니다.

---

## 조 상세 페이지 구성 요소

### 0–1. 조 수정 & 집회 선택

관리자 전용 조 수정 버튼. 집회 연도 및 회차 선택.

### 2–3. 조원 현황 & 데이터

해당 조 입실 현황 요약 표시. 조원 클릭 시 수정 페이지 이동.

### 4–5. 입·퇴실 시각 입력

조원별 입실 및 퇴실 시각을 직접 입력. 1분마다 상태 자동 반영.

### 6–7. 조원 추가 & 제거

조원 제거 버튼으로 삭제. 하단 추가 버튼으로 신규 조원 등록.

조원 클릭 시 개별 수정 페이지로 즉시 이동 — 빠른 현장 관리 지원.

---

## 조원 추가 및 데이터 관리

### 필수 입력 항목

1. **역할 구분** (필수) — 조장 / 부조장 / 조원
2. **실명 입력** (필수)
3. **성별 선택** (필수) — 남 / 여

### 선택 입력 항목

2. **계정 연동** (선택) — 회원가입 계정 연동 가능
3. **핸드폰 번호** (선택)
4. **입실 시각** (선택) — 입력 시 자동 상태 변경 (1분마다)
5. **숙소 배정** (선택) — 미배정 시 본부 미배정 상태

**저장** 버튼으로 모든 입력 정보를 최종 등록합니다.

---

## 입실 상태 자동 변경 및 권한

### 상태 자동 변경 흐름

**입실 전** (아직 도착 전) → 입실 시각 도달 (1분마다 자동) → **입실** (현재 참석 중) → 퇴실 시각 도달 (1분마다 자동) → **퇴실** (퇴실 완료)

### 사용자 등급별 조원 관리 권한

### Tier 1 · 참가자

- 플랫폼 접근 불가
- 조원 추가·수정 불가

### Tier 2 · 조장 / 부조장

- 전체 조 정보 조회
- 자기 조 조원 추가
- 부조장·조원 권한 부여
- 타 조 관리 불가

### Tier 3 · 수련회 회장단

- 전체 조 조회·수정
- 조 추가·삭제
- 전체 조원 추가·수정
- 숙소 배정 · 대시보드 전체
